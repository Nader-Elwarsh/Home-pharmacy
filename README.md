# صيدلية البيت — P0 (تأسيس المشروع)

تطبيق ويب PWA بالعربية (RTL) لإدارة أدوية المنزل والملف الصحي للأسرة. هذه المرحلة تضع الأساس فقط.
الوثيقة المعمارية: `docs/ARCHITECTURE.md`.

## التشغيل

```bash
npm install
npm run dev          # تطوير
npm run typecheck    # فحص الأنواع
npm run lint         # قاعدة فصل الطبقات
npm test             # Vitest
npm run build        # بناء الإنتاج
npm run e2e          # Playwright (يبني ويشغّل preview تلقائيًا)
# أول مرة لـ Playwright: npx playwright install chromium
```

## ما تم تنفيذه في P0

- React + Vite + TypeScript، SPA بخمس صفحات (الرئيسية، الخزانة، الصحة، الأسرة، المزيد).
- RTL و`lang="ar"`، تخطيط بخصائص منطقية، شريط تنقل سفلي (هاتف) وقائمة جانبية (حاسوب).
- PWA: manifest وService Worker (vite-plugin-pwa) وأيقونات.
- Dexie: قاعدة `home-pharmacy` بجدول `appMeta` فقط، مع مستودع وخدمة حقيقية (تسجيل أول فتح).
- فصل الطبقات: `ui → core/services → core/repositories → core/database`، مفروض بقاعدة ESLint وباختبار.
- نظام تصميم أولي: حالات بنص ورمز ولون، أزرار ≥ 44px، خط أساس 18px.
- الوحدات غير المنفذة تُعرض بوضوح كـ"قريبًا" مع رقم المرحلة، بلا أزرار وهمية.

## حالة التحقق (صراحةً)

| الفحص | الحالة |
|---|---|
| صياغة جميع ملفات TS/TSX (24 ملفًا) | تم فحصها: 0 أخطاء |
| قاعدة فصل الطبقات (سكربت مكافئ للاختبار) | تم فحصها: 0 مخالفات |
| `npm install` / `typecheck` / `build` | **لم تُشغَّل** (تثبيت الحزم معطّل في بيئة الإنشاء) |
| `npm test` (Vitest) | **لم يُشغَّل** |
| `npm run lint` | **لم يُشغَّل** |
| `npm run e2e` (Playwright) | **لم يُشغَّل** |
| اختبار العمل دون اتصال فعليًا | **لم يُختبر** |

لذلك **P0 غير معتمدة** إلى أن تنجح الأوامر أعلاه عندك. إصدارات الحزم في `package.json` لم تُتحقق من توافقها،
فإن فشل `npm install` بسبب تعارض إصدارات فهذا أول ما يُصلَح.

## تجربة يدوية

1. `npm run dev` ثم افتح الرابط على الهاتف أو الحاسوب.
2. تنقل بين الصفحات الخمس، وتأكد أن الرئيسية تعرض "قاعدة البيانات المحلية تعمل".
3. `npm run build && npm run preview`، افتح التطبيق مرة، ثم اقطع الإنترنت وأعد التحميل: يجب أن يفتح.

## القيود المعروفة

- لا Firebase ولا تسجيل دخول بعد (P1).
- أيقونات مؤقتة (شكل صليب)، تُستبدل بهوية نهائية لاحقًا.
- iOS: دعم PWA والتخزين المحلي له قيود، تُختبر في P13.
